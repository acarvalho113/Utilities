# Instruções do projeto

Este repositório é um índice pessoal de repositórios úteis do GitHub. Quando o usuário enviar um link de repositório para adicionar:

1. Consulte o `README.md` para entender as categorias, o formato e o tom já usados.
2. Confira a página e, quando necessário, os arquivos oficiais do repositório enviado para identificar sua finalidade e licença. Não invente detalhes; se a licença não estiver clara, indique que ela não foi identificada em vez de presumir uma.
   - Se o usuário enviar apenas o nome do projeto, pesquise no GitHub e confirme a correspondência pelo proprietário, nome, descrição e conteúdo oficial. Use menções a trending ou popularidade como pistas, não como prova. Se houver mais de uma correspondência plausível ou não for possível confirmar a identidade, não adicione; apresente os candidatos como links para o usuário revisar.
3. Acrescente uma entrada na categoria existente mais adequada, mantendo o idioma e o padrão do README. Inclua o link, uma descrição concisa e, quando fizer sentido para a categoria, quando usar e a licença.
4. Antes de concluir, revise a formatação do README, incluindo a hierarquia de títulos e listas, e verifique os links das entradas adicionadas ou alteradas. Corrija URLs de exemplo, placeholders ou links obviamente malformados; confirme o destino correto em fonte confiável antes de substituir um link. Não altere links não relacionados sem necessidade.
5. Preserve o restante do README e evite duplicar uma entrada que já exista.
6. Ao concluir, informe brevemente em qual seção adicionou o repositório ou quais problemas de formatação corrigiu.
7. Depois de preparar e revisar as alterações, pergunte se o usuário autoriza fazer o commit e o push. Só execute essas operações após confirmação explícita; se autorizado, inclua apenas as alterações deste trabalho e informe o resultado.

O fluxo padrão é adicionar o repositório enviado diretamente ao README; não é necessário pedir confirmação para escolhas editoriais rotineiras. A confirmação de commit e push é sempre uma etapa separada.
