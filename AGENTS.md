# Instruções do projeto

Este repositório é um índice pessoal de repositórios úteis do GitHub. Quando o usuário enviar um link de repositório para adicionar:

1. Consulte o `README.md` para entender as categorias, o formato e o tom já usados.
2. Confira a página e, quando necessário, os arquivos oficiais do repositório enviado para identificar sua finalidade e licença. Não invente detalhes; se a licença não estiver clara, indique que ela não foi identificada em vez de presumir uma.
3. Acrescente uma entrada na categoria existente mais adequada, mantendo o idioma e o padrão do README. Inclua o link, uma descrição concisa e, quando fizer sentido para a categoria, quando usar e a licença.
4. Preserve o restante do README e evite duplicar uma entrada que já exista.
5. Ao concluir, informe brevemente em qual seção adicionou o repositório.

O fluxo padrão é adicionar o repositório enviado diretamente ao README; não é necessário pedir confirmação para escolhas editoriais rotineiras.
